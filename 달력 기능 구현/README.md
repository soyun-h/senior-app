# 오느른 달력

이 폴더에서 Expo SDK 58 프로젝트를 실행합니다. Node.js 22.13 이상인 22 LTS 또는 Node.js 24.3 이상인 24 LTS를 사용하세요.

```sh
npm ci
npm start -- --clear
```

SDK 58을 지원하는 Expo Go에서 QR 코드를 열거나, 개발 서버에서 `w`를 눌러 브라우저로 확인합니다.

기기의 오늘 날짜에는 초록색 원형 테두리가 표시되고 오늘의 기록이 열립니다. 날짜를 누르면 반투명 연두색 원이 생기고 해당 날짜의 기록이 열립니다. 기록이 비어 있는 날짜는 카드 하단에 `이날의 기록 사진이 없어요.`를 표시합니다.

오늘 날짜의 카드에서 **기록 사진 찍기**를 누르면 카메라가 열립니다. 사진이 이미 있을 때는 카드의 날짜 제목을 눌러 사진을 추가합니다. 갤러리는 가로로 밀거나 세 번째 사진의 **+N**을 눌러 넘길 수 있습니다.

Expo 앱의 다른 촬영 화면에서 날짜별 기록에 연결하려면 촬영을 마친 뒤 `await savePhotoRecord({ uri, capturedAt })`를 호출합니다. `capturedAt`은 촬영 시각을 담은 `Date`입니다. Android와 iOS에서는 사진을 앱의 문서 폴더로 복사하며, 웹에서는 이 브라우저의 IndexedDB에 저장합니다.

기준 화면에서 달력 앱 영역은 360×729입니다. 앱은 이 영역의 좌표와 크기를 화면 너비에 맞춰 같은 비율로 적용합니다. 날짜가 여섯 줄인 달에는 마지막 줄 아래로 카드가 내려갑니다. 하단 시스템 탐색 영역은 기기가 표시합니다.
