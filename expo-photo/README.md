# 오느른 Expo 사진 기록

팀 일정 앱과 음성 홈에 맞춘 Expo SDK 58 프로젝트입니다.

```bash
cd expo-photo
npm ci
npm start
```

휴대폰과 PC를 같은 Wi-Fi에 연결하고 Expo Go에서 실행 화면의 QR을 스캔합니다. 카메라 권한을 허용하고 **사진 기록 촬영 → 기록하기 → 기록 완료!** 순서로 진행합니다. 등록 화면은 세로로 스크롤할 수 있으며, 목록에서 미션을 선택하면 등록 버튼이 활성화됩니다.

사진과 미션 정보는 휴대폰 앱 저장소의 `oneureun-photo-records/날짜`에 보관합니다. 팀 달력의 사진 폴더 형식과 같으며, Expo 프로젝트가 분리된 동안 저장소는 각 앱에 속합니다. 완료 화면의 가족 공유 버튼에서 사진을 공유하거나 기록 문구를 복사합니다.

- Expo Go 개발 서버 기본 포트는 8089입니다.
- 카메라 촬영과 공유는 Android·iOS 실물 기기에서 확인합니다.
