# senior-app

**프로젝트:** 노년층 AI 아바타 기반 일정 관리 서비스 (all it)

## dev 원본 브랜치 통합

- `src/weather-schedule-app/`은 허소윤의 날씨와 일정, 문한나의 캐릭터와 대사를 연결한 Expo 앱입니다.
- 루트 `index.html`, CSS, 에셋과 `voice.mjs`는 김가은의 웹 프로토타입입니다. 루트에서 `node serve.mjs`를 실행하면 `http://127.0.0.1:4173`으로 열립니다.
- 팀원의 디자인과 와이어프레임은 [design/individual/](design/individual/)과 [wireframes/](wireframes/)에 있습니다. 개인별 작업 기록과 기존 HTML은 [members/](members/)에 있습니다.

로컬 실행 방법은 [ANDROID_DEVELOPMENT.md](docs/ANDROID_DEVELOPMENT.md)에서 확인할 수 있습니다.

출시팀 소유 프로젝트로 Supabase, GitHub Pages 및 Android를 구성하는 절차는 [RELEASE_GUIDE.md](docs/RELEASE_GUIDE.md)에 있습니다.
