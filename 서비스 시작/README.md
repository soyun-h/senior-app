# 오느른 서비스 시작

Expo SDK 58 프로젝트입니다. 이 폴더에서 실행합니다.

```powershell
npm ci
npm start
```

PC와 휴대폰을 같은 Wi-Fi에 연결하고 실행 터미널에 나온 QR을 SDK 58과 호환되는 Expo Go로 스캔합니다. 사용 중인 QR은 현재 개발 서버 주소에 연결됩니다. IP 주소가 바뀌면 터미널에 표시되는 새 QR을 사용하세요.

시작 이미지가 표시되면 1.5초 동안 유지한 뒤 로그인 화면으로 서서히 전환합니다. 이름과 생년월일을 입력하고, 가족 연락처를 확인 및 등록한 뒤, 다섯 장의 사진을 좌우로 넘겨 친구를 선택합니다. 가족 연락처는 건너뛸 수도 있습니다. 등록 정보는 이 Expo 앱의 기기 내 SecureStore에 저장됩니다. 앱을 다시 열면 저장된 값이 입력 화면에 채워집니다.

화면 원본은 `assets/screens`에 360×780 PNG로 보관합니다. 고밀도 디스플레이용 `@3x` 이미지는 원본의 비율과 요소 위치를 그대로 사용하면서 글자와 윤곽을 보강합니다. 앱의 화면 배치 기준은 360×780이며, 화면 높이가 부족하면 세로 스크롤을 사용합니다. 선택 화면에 표시되는 사진은 `origin/문한나/members`의 `weather-schedule-app/src/features/avatar/characterAssets.ts`에 연결된 다섯 프로필 사진입니다.

마지막 화면은 첨부된 ‘서비스 시작 - 로그인 창 이후’ 이미지를 표시합니다. 아바타 단계에서는 선택한 캐릭터를 저장합니다. 이 프로젝트는 서비스 시작 흐름을 독립 실행합니다.
