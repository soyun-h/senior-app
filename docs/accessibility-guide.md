# Accessibility Guide — 노년층 일정 관리 및 기억 보조 앱

- 버전: 0.1 (팀 검토용 제안)
- 평가 범위: 온보딩, 아바타 선택, 홈, 할 일·일정 등록, 알림·영상통화, 처방전 AI 인식, 사진 인증, 달력
- 기준: WCAG 2.2 Level A/AA 중 적용 가능한 성공 기준 + Android 접근성 가이드
- 주의: 본 문서는 첨부된 정적 화면을 바탕으로 한 **예비 진단**이며, 실제 위반 판정은 색 대비 측정·기능 동작·TalkBack 점검을 거쳐 확정한다.

## 1. 설계 원칙

1. **인지 가능**: 글씨·상태·알림은 색이나 소리 한 가지에만 의존하지 않는다.
2. **운용 가능**: 중요한 조작은 큰 터치 영역, 명확한 버튼, 취소 및 재시도로 지원한다.
3. **이해 가능**: 일정 등록부터 확인까지 단계를 간결하게 유지하고 오류를 구체적으로 설명한다.
4. **견고성**: TalkBack, Android 글자 크기 설정, 외부 입력 보조 기능을 지원한다.
5. **의료 안전성**: AI 추출 복약 정보는 사용자가 원문과 대조·수정·확인한 뒤 저장한다.

| A10 | 앱 전체 | 시스템 글자 확대·TalkBack 미지원 여부 확인 필요 | 1.4.4 AA, 4.1.2 A, 1.3.2 A | 높음 | 동적 글자 확대·스크롤·읽기 순서·접근성 레이블 테스트 | 각 원본 → 확대/스크린리더 점검 캡처 |

> 정적 화면만으로 버튼의 실제 dp 크기, 명도 대비 수치, 스크린리더 동작, 오류 처리 여부를 확정할 수 없다. 위 항목은 '확정 위반'이 아니라 '위험 또는 위반 의심'이다.

## 4. 개선 전/후 화면 제출 체크리스트

각 대표 화면에 대해 동일 크기의 원본과 수정 화면을 나란히 배치하고, 바뀐 컴포넌트에 번호를 부여한다.

- [ ] 홈: 반투명 카드 대비 강화, 완료/대기 텍스트 표시
- [ ] 일정 등록: 날짜·반복·알림 버튼 48×48dp 이상, 간격 확대
- [ ] 처방전 인식: AI 정보 검토·수정·최종 확인 화면 추가
- [ ] 영상통화: 음성 내용 텍스트·다시 듣기
- [ ] 달력: 색상 외 완료 건수·상태·범례 표기

## 5. 검증 방법과 팀 합의 사항

1. Figma에서 모든 주요 텍스트/배경 조합의 명도 대비 검사 결과를 기록한다.
2. 실제 Android 앱에서 Accessibility Scanner로 터치 크기·레이블 점검, TalkBack으로 이동 순서·상태 안내 확인한다.
3. Android 시스템의 글꼴 크기를 키운 뒤 겹침·잘림·가려짐을 확인한다.
4. '처방전 촬영 → AI 인식 → 항목 수정 → 저장'을 시나리오 테스트하고, 인식 실패 시 대체 경로를 점검한다.
5. 팀원 전원이 적용 범위, 심각도, 예외, 개선 우선순위를 논의해 최종 확정한다.
