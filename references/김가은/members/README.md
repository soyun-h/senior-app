# 사진 미션 인증

Node.js 18 이상에서 저장소 폴더의 터미널을 열고 `node serve.mjs`를 실행합니다. [사진 인증 화면](http://localhost:4173/?screen=photo)을 바로 열거나 [앱](http://localhost:4173/)의 알람 화면에서 **사진 인증 열기**를 누릅니다.

카메라 권한을 허용해 촬영하세요. 카메라를 사용할 수 없으면 기기의 사진을 선택할 수 있습니다. 미션을 선택해 등록한 뒤 가족에게 공유하세요. 파일 공유를 지원하지 않는 브라우저에서는 사진 저장과 메시지 복사를 이용할 수 있습니다.
