# 일정 화면 에셋

사용자가 제공한 schedule-assets.zip에서 실제 화면에 필요한 파일만 추출했습니다.
원본 경로의 `icons:`, `images:` 디렉터리명은 정상 폴더명으로 정리했습니다.
원본 PNG/SVG 내용은 변경하지 않았습니다. SVG는 ScheduleAsset.tsx에 동일한 XML로 임베드합니다.
같은 일정/홈/달력 아이콘과 홈 PNG는 기존 assets/design 에셋을 재사용합니다.

- icons/: bell, plus, check, back, edit 원본
- images/: 목록/입력 배경, 알림 켬/끔 카드 표면 원본
- decoration/: 등록 버튼, 토글, 선택 표면 원본

카드·버튼·토글은 원본 그림을 표면으로 쓰되 실제 React Native 입력/터치 컴포넌트로 구성합니다.
화면 전체를 이미지로 대체하지 않습니다.
삭제 아이콘·삭제 버튼·삭제 토스트는 이번 범위가 아니므로 추출하거나 사용하지 않았습니다.
선택 표면 두 SVG는 향후 세부 조정용으로 보관하며 현재 선택 UI는 같은 팔레트의 컴포넌트 표면을 사용합니다.
SVG filter의 그림자/블러는 플랫폼별 렌더링 차이가 있을 수 있으며 Android 실기기 검증이 필요합니다.
