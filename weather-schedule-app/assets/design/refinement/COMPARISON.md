# 시각 보정 비교

완성 시안의 Android 시스템 바 50px을 제외한 360×730 앱 영역을 기준으로 했습니다.
390×844에서는 390×791 앱 영역을 중앙 배치하고 나머지는 레터박스로 처리합니다.
실제 개발 서버 Chromium에서 8초 자동 전환을 따라 촬영한 PNG를 preview-screenshots에 저장했습니다.
Figma 시안을 앱 화면 PNG로 대체하지 않았습니다.

## 배경 비교

배경 원본은 수정하지 않고 시안의 노출·대비에 맞춘 흰색 보정 레이어를 적용했습니다.
아래는 공통 배경 노출 영역 RGB 평균 절대 오차(0~255)이며 글자·아바타·카드 영역은 제외했습니다.
0은 픽셀 일치입니다. 폰트·렌더러와 배경 크롭 차이가 있어 완전한 픽셀 일치는 아닙니다.

| 상태 | 캡처 크기 | 배경 오차 |
|---|---|---|
| clear | 390×844 | 11.4 |
| cloudy | 390×844 | 12.3 |
| rain | 390×844 | 6.9 |
| snow | 390×844 | 9.4 |
| thunder | 390×844 | 20.6 |

## 원본·배치

- SVG 원본 문자열을 SvgXml로 전달하며 경로·색상·stroke·viewBox·원본 치수를 변경하지 않았습니다.
- 원본 XML은 HomeIcon.tsx와 icons/ 파일 간 문자열 일치 검사를 통과했습니다.
- 홈 버튼 PNG를 재가공하지 않고 75×75 박스 안에 투명 여백까지 표시합니다. 실제 녹색 원은 약 50px이며 클릭 영역은 별도 Pressable입니다.
- Navigation Bar.png는 제공본 그대로 보관하되 전체 바를 이미지로 대체하지 않았습니다.
- 완료·대기 아이콘 원본은 ZIP에 없어 해당 두 아이콘은 기존 것을 유지했습니다.
- 배경 블러는 expo-blur로 적용하고 표면 틴트·상단 하이라이트·테두리를 겹쳤습니다.
- Android 31+는 blurTarget과 native blur를 사용하며 하위 버전은 반투명 표면으로 대체됩니다. 실제 기기의 blur 품질·성능은 미검증입니다.
- 시스템 폰트는 유지합니다. 원본 폰트 파일이 없어 완전 일치는 보장하지 않습니다.
- 아바타 기본 이미지를 유지하고 시안에 맞춰 표시 폭만 300으로 보정했습니다.

## 검증

TypeScript, Expo SDK 의존성 검사, 날씨 로직 테스트 2개, Android 번들 생성 통과.
최종 웹 5상태 캡처 중 pageerror 0개, PNG 5개 모두 디코딩 성공 및 390×844 확인.
날씨 순환 훅·날씨 처리 함수·아바타 타입·app.json은 기존 커밋과 바이트 일치합니다.
